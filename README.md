# 산업부 공공 AX 실습 강의

2026년 8월 6일 산업통상자원부 실무자를 위한 AI 에이전트 실습 강의 자료입니다. 채팅형 AI와 에이전트의 차이를 설명하고, 여러 기관의 데이터를 자동으로 결합해 실제 산출물을 만드는 과정을 보여줍니다.

## 라이브 페이지

### [지역산업 시그널 대시보드 열기 →](https://hosungseo.github.io/motie-agent-lecture/dashboard/)

관세청·한국산업단지공단·KEPCO 데이터를 17개 시도 기준으로 자동 결합한 오프라인 안전형 정적 대시보드입니다.

## 핵심 메시지

> 채팅은 내가 일하는 동안 AI가 돕는 것, 에이전트는 AI가 일하는 동안 내가 다른 일을 하는 것.

대화가 끝난 뒤 답변만 남는지, 다시 쓸 수 있는 산출물이 남는지를 기준으로 AI 활용 방식을 구분합니다.

## 주요 데모

- **지역산업 현황판** — 3개 기관의 데이터를 결합해 주의 지역과 산업 신호를 자동 판정
- **역방향 메일 에이전트** — 업무 메일 수신, 유형 분류, 회신, 처리대장 기록을 자동화하는 실습 데모
- **오프라인 실행** — API 결과를 빌드 시점에 HTML에 포함해 행사장 네트워크 없이도 발표 가능

## 대시보드 기능

- 17개 시도 전국 요약과 복합 주의 신호
- 상태 필터, 지역 검색, 지표별 정렬
- 수출입 증감률, 산업단지 가동률, 산업용 전력 고객 순증감 비교
- Factoryon 등록 공장 샘플
- 모바일·키보드·스크린리더·모션 감소 환경 대응

## 로컬 실행

```bash
cd dashboard
npm install
npm test
npm run build:static
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. `npm run build:static`은 저장된 `data/data.json`으로 화면만 다시 생성하며 외부 API를 호출하지 않습니다.

## 데이터 소스

- 관세청 시도별 수출입실적
- 한국산업단지공단 전국산업단지현황통계
- KEPCO 산업분류별 전기사용고객 증감
- Factoryon 공장등록 생산정보 샘플

## 저장소 구조

```text
dashboard/  지역산업 시그널 정적 대시보드와 데이터 빌드 파이프라인
agent/      역방향 메일 에이전트 데모
deck/       강의 덱

```

세부 강의 구성과 운영 리스크는 [`PLAN.md`](./PLAN.md)에서 확인할 수 있습니다.
